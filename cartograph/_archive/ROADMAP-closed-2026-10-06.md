- **A08 · ✅ CLOSED 2026-08-04 — the three membership sites are now ONE function** (`cartograph/membership.mjs`). *(Found while ruling the precedence; fixed on Jacob's go-ahead.)* `bake-buildings.js`'s comment claimed the cull *"must match `pipeline.js` exactly so 2D + slab agree on membership"* — it did not: for a footprint with <3 vertices, pipeline pre-clip **kept**, pipeline post-derive **centroid-tested**, the bake **dropped**. So the 2D Designer could show a building the slab does not.
  - **The fix is one function, not one rule pasted three times** — that is what let it drift. All three sites now call `createMembershipFilter().decide(id, ring)`; both hand-copied `pointInPolygon` helpers were excised.
  - **The degenerate case is now RULED and LOUD:** a <3-vertex ring has no trustworthy centroid, so membership is **UNDECIDABLE**. `hide`/`activate` still apply (id-keyed, need no geometry); past that the building is **KEPT and COUNTED**, and `report()` prints a ⛔ line naming ids. **Membership is not a data-quality culler** — a malformed footprint is an **intake** defect, and dropping it silently loses the building *and its content*. The bake's mesh loop separately reports what it cannot extrude (it already skipped them, silently).
  - **⚠️ A near-miss worth recording:** `nb.polygon`/`nb.exclusions` are `{x,z}` **objects**; both old helpers hard-coded that. Unifying on an `[x,z]` assumption would have read `undefined` for every coordinate and dropped **every** building in any scene with a polygon — rendering as an empty map, not an error. The shared helper is deliberately format-agnostic and says so.
  - **Proof, not assertion — `scratch/a08-membership-equivalence.mjs`** (read-only, no pour/bake): replays the three historical predicates *verbatim* against the new one over every scene's committed artifacts — **72,735 decisions, ZERO disagreements**, including both polygon scenes (hipointe-demun 4-pt, centrum 815-pt), so the ring-format hazard is proven closed rather than reasoned about. Plus two synthetic cases that **pairwise distinguish all three old rules**, and an assertion that `activate` beats an exclusion loop. ⭐ **Zero degenerate footprints exist in any scene today (raw or clean), so this changes no current output — it is armour for town #2.**
